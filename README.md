# JokerNg Homebrew Tap

## Install

```bash
brew tap JokerNg/tap
brew install --cask codex-touchbar-monitor
```

## Update

```bash
brew upgrade --cask codex-touchbar-monitor
```

The cask downloads release DMG files from [CodexTouchBarMonitor](https://github.com/JokerNg/CodexTouchBarMonitor/releases).
